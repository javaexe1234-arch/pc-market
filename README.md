# PC Market

Интернет-магазин комплектующих для ПК на русском и узбекском, с ценами в сумах, конструктором сборки, проверкой совместимости и оценкой FPS.

## Запуск

База данных и файлы чеков находятся в Neon, в проекте `shy-bird-16154133`, регион `aws-us-east-2`. Параметры подключения записывает в `.env` Neon CLI:

```bash
npm install
neon link --project-id shy-bird-16154133 --branch production
npm run db:migrate
npm run dev
```

Сайт откроется на http://localhost:3000. Остальные настройки описаны в `.env.example`.

## Neon

- **База данных (Lakebase Postgres):** приложение работает через Prisma и пул соединений `DATABASE_URL`, а миграции идут через прямое соединение `DATABASE_URL_UNPOOLED`. Схема описана в `prisma/schema.prisma`, миграции лежат в `prisma/migrations`.
- **Хранилище чеков (Object Storage):** приватное хранилище `receipts` объявлено в `neon.ts`. Код работы с ним находится в `src/lib/receipt-storage.ts`. Ключи доступа `AWS_*` к хранилищу записывает в `.env` команда `neon deploy` или `neon env pull`. Чеки видит только сервер: сайт отдаёт их только в админке.
- **Ветки:** `production` — рабочие данные магазина. `test` — отдельная пустая ветка для автотестов, её адрес записан в `TEST_DATABASE_URL` в `.env`. Тесты создают на ней свои записи и удаляют их после себя.
- **Изменение схемы:** поправьте `prisma/schema.prisma` и создайте миграцию командой `npx prisma migrate dev --name <название>`. Сначала проверьте её на отдельной ветке (`neon checkout <имя> --create`), затем примените к production командой `npm run db:migrate`.
- **Старые данные:** прежняя локальная база SQLite `prisma/dev.db` уже перенесена командой `npm run db:import-sqlite`. Эта команда ничего не делает, если в Neon уже есть товары.

## Команды

- `npm test`: все тесты. Тесты заказов и остатков работают с веткой `test` в Neon и пропускаются, если `TEST_DATABASE_URL` не задан.
- `npm run build`: production-сборка.
- `npm run db:migrate`: применяет новые миграции к базе из `DATABASE_URL`.
- `npm run db:seed`: загружает начальные данные. Записи с теми же `slug` перезаписываются.

## Где что менять

- Товары и цены: `prisma/seed/products.ts`.
- Игры и ориентиры FPS: `prisma/seed/games.ts`.
- Правила совместимости: `src/lib/compatibility.ts`.
- Формула FPS: `src/lib/fps.ts`.
- Тексты интерфейса: `messages/ru.json`, `messages/uz.json`.

- Размещение деталей в 3D и 2D: `src/lib/scene-layout.ts`.
- 3D-сцена и модели: `src/components/builder/viewer/`.
- Цвета тёмной и светлой тем: `src/app/globals.css`.

После правки файлов в `prisma/seed` выполните `npm run db:seed`.

## Админка

Создайте секретный адрес и пароль. Команда запишет их в `.env` и покажет на экране:

```bash
npm run admin:setup
```

После этого перезапустите сайт. Пока адрес и пароль не заданы, админка отключена.

- **Заказы:** просмотр чека, подтверждение и отклонение оплаты. При отклонении товары возвращаются на склад.
- **Товары:** цены и остатки прямо в таблице, добавление и изменение товаров. Товар нельзя удалить, но его можно скрыть, чтобы не терять историю заказов.
- **Игры:** добавление, изменение и скрытие игр в расчёте FPS.

Чтобы сменить адрес или пароль, очистите `ADMIN_PATH` или `ADMIN_PASSWORD` в `.env` и выполните команду ещё раз. После смены пароля все входы сбрасываются. Если попытки входа исчерпаны, подождите 15 минут или перезапустите сайт.

На настоящем сервере открывайте сайт только по HTTPS.

**Не запускайте `npm run db:seed` на работающем магазине:** команда вернёт цены, остатки и описания товаров к начальным значениям.

## 3D-модели

Скачанные модели лежат в `public/models`. Их авторы и лицензии перечислены в `src/lib/model-credits.ts` и показаны на сайте под окном просмотра. Модели с лицензией CC-BY можно использовать только с указанием автора, поэтому этот блок нельзя убирать. При добавлении файла дополните этот список: тест `tests/model-files.test.ts` проверяет, что каждая модель указана в нём.

## Telegram

Чеки приходят в Telegram через вашего бота. Настройка:

1. Создайте бота в [@BotFather](https://t.me/BotFather) и впишите его токен в `TELEGRAM_BOT_TOKEN` в файле `.env`.
2. Напишите своему боту любое сообщение.
3. Выполните `npm run telegram:setup`: команда покажет id вашего чата. Впишите его в `TELEGRAM_CHAT_ID`.
4. Выполните `npm run telegram:setup` ещё раз: бот пришлёт проверочное сообщение.
5. Впишите реквизиты для оплаты в `PAYMENT_CARD_NUMBER` и `PAYMENT_CARD_HOLDER`.
6. Перезапустите сайт.

Файл `.env` содержит секреты: не публикуйте его. Чеки хранятся в приватном хранилище Neon `receipts`, а не на диске сервера.
